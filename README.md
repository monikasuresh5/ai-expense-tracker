# AI Expense Tracker

Full-stack AI-powered expense tracker built with Spring Boot, React, MySQL, and Gemini API. Log, categorize, and analyze expenses with AI-generated spending insights.

## Tech Stack
- **Backend:** Spring Boot, Spring Data JPA, MySQL
- **Frontend:** React
- **AI:** Google Gemini API
- **Auth:** JWT-based authentication

## Planned Features
- User signup/login with JWT auth
- Add, edit, delete expenses with category, amount, date, notes
- Dashboard with monthly totals and category-wise breakdown
- AI-powered auto-categorization and natural-language spend summaries
- Budget limit alerts
